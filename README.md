## Publish with GitHub Pages
1. Sign in to GitHub and create a repository, for example `erp-comparison-matrix`.
2. Upload `index.html` to the repository root and commit the change.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After the workflow completes, open the published site from the Pages settings. A project site usually uses `https://<username>.github.io/<repository-name>/`.

Official GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## SEO notes
- `robots`, `googlebot`, and `bingbot` meta directives are set to `index, follow`. These request crawling/indexing but cannot guarantee that a search engine will index the page.
- The canonical URL points to the original Top Dynamics Partners resource, indicating the original resource is preferred. Review the canonical strategy if you intend this GitHub Pages copy to be indexed as a separate, independent page.
- Exactly three clickable links are included: one target resource link using the target keyword, one homepage link using the brand name, and one relevant official Microsoft documentation link. Contact details are plain text to preserve the exact link count.
- GitHub Pages publishes static content. Published sites are publicly accessible; do not commit confidential information.
